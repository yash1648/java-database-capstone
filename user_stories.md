# User Stories

## Admin User Stories

### Title: Manage Doctor Accounts
**Story:**  
As an admin, I want to manage doctor accounts so that I can control system access.

**Acceptance Criteria:**
- Admin can create a new doctor account.
- Admin can update doctor details.
- Admin can delete doctor accounts.
- Admin can view all registered doctors.

**Priority:** High  
**Story Points:** 5

---

### Title: View All Appointments
**Story:**  
As an admin, I want to view all appointments so that I can monitor hospital activity.

**Acceptance Criteria:**
- Admin can view a list of all appointments.
- Admin can filter appointments by doctor.
- Admin can filter appointments by patient.
- Admin can view appointment status.

**Priority:** High  
**Story Points:** 4

---

## Patient User Stories

### Title: Register Patient Account
**Story:**  
As a patient, I want to register an account so that I can book appointments.

**Acceptance Criteria:**
- Patient can create an account with name, email, and password.
- System validates email uniqueness.
- System stores patient information securely.

**Priority:** High  
**Story Points:** 5

---

### Title: Book Appointment
**Story:**  
As a patient, I want to book appointments with doctors so that I can receive medical consultation.

**Acceptance Criteria:**
- Patient can view available doctors.
- Patient can select a date and time slot.
- System confirms the appointment booking.
- System prevents booking of unavailable slots.

**Priority:** High  
**Story Points:** 6

---

### Title: View Appointment History
**Story:**  
As a patient, I want to view my appointment history.

**Acceptance Criteria:**
- Patient can see a list of past appointments.
- Patient can view doctor name and appointment time.
- Patient can see appointment status.

**Priority:** Medium  
**Story Points:** 3

---

## Doctor User Stories

### Title: View Scheduled Appointments
**Story:**  
As a doctor, I want to view my scheduled appointments.

**Acceptance Criteria:**
- Doctor can view upcoming appointments.
- Doctor can see patient details.
- Doctor can filter appointments by date.

**Priority:** High  
**Story Points:** 4

---

### Title: Update Availability Schedule

As a doctor, I want to update my availability schedule.

**Acceptance Criteria:**
- Doctor can add available time slots.
- Doctor can update existing time slots.
- Doctor can remove unavailable time slots.

**Priority:** High  
**Story Points:** 5

---

### Title: Manage Patient Prescriptions
