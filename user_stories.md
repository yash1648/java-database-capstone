# User Stories

## Admin User Stories
- As an admin, I want to manage doctor accounts so that I can control system access.
- As an admin, I want to view all appointments so that I can monitor hospital activity.

## Patient User Stories
- As a patient, I want to register an account so that I can book appointments.
- As a patient, I want to book appointments with doctors so that I can receive medical consultation.
- As a patient, I want to view my appointment history.

## Doctor User Stories
- As a doctor, I want to view my scheduled appointments.
- As a doctor, I want to update my availability schedule.
- As a doctor, I want to manage patient prescriptions.
